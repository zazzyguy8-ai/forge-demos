# Forge — demo tools

Live reference builds, one per niche. Static export of the Forge repo.

**https://zazzyguy8-ai.github.io/forge-demos/**

Demo creator names are placeholders. The unlock buttons open the unlocked
preview instead of Stripe, so a creator can see exactly what a buyer gets.

Regenerate and republish with `npm run deploy:pages`. This branch is a build
artifact and is force-pushed; do not edit it by hand.
